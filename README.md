# Tern

A synthesis-first hardware description language. Everything that compiles is
hardware, every signal is typed with a width and a clock domain, tests live
beside the design, and the compiler emits clean SystemVerilog.

This repository is the reference implementation: one portable C11 (C99-compatible)
program, `tern`, with no third-party dependencies.

*Work in progress — see `docs/tern-spec.pdf` for the language specification.*
